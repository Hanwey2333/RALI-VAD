# RALI-VAD

Core reference implementation for:

**RALI-VAD: Reliability-Aware Weakly Supervised Video Anomaly Detection with Training-Only Multimodal Semantic Supervision**

## Release status

This private repository is being prepared for the paper submission. The planned
release contains the core research implementation rather than a complete
turnkey reproduction package.

The public release will focus on:

- the Stage 1 visual anomaly detector components used in the paper;
- Reliability-Aware Label Integration (RALI);
- Noise-Adaptive Refinement (NAR);
- core objectives and target-bank update logic;
- the final configuration and semantic-record schema needed to understand the
  implementation.

The repository will not redistribute UCF-Crime, XD-Violence, or UBnormal, their
extracted features, private API credentials, experiment logs, or large model
checkpoints. Dataset acquisition and preprocessing remain subject to the
original providers' terms.

## Availability

Source files and documentation will be added after a private release audit.
The repository will be made public after the authors verify the file list,
licenses, paths, and absence of credentials.
